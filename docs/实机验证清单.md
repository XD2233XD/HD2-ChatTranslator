# 实机验证清单

每一步都有**可核对的日志证据**；没有证据就不算通过。

## 0. 前置

- [ ] 游戏完全退出（不是最小化）
- [ ] 控制台在跑：`http://127.0.0.1:8731/`
- [ ] 设置里已填 API Key，**快速测试**能翻出一句中文
- [ ] 安装页显示：Bingus 已安装、本 Mod 已安装

## 1. 加载

启动游戏，等待进入飞船。

看 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\HD2ChatTranslator.log`：

- [ ] `START version=0.1.0 (HD2 Chat Translator)`
- [ ] `CONFIG read=zh-CN send=en inbound=on outbound=on tag=code ...`
- [ ] `ARMED mode=mem ...`

失败分支：

| 现象 | 含义 | 处理 |
|---|---|---|
| 日志文件不存在 | 游戏没加载 patch_1 | 看 `BingusSharedLoader.log` 是否存在；不存在说明 patch_2 也没加载 → 改用 Arsenal |
| 有 `ERROR=BSL_API_1_REQUIRED` | 加载器版本/API 不对 | 确认 patch_2 是 v20 |
| 有 `START` 无 `ARMED` | 场景未就绪或偏移失效 | 等进入飞船；仍无则核对 build 25480438 |
| `WAIT resolve=...` | 找不到 root/manager | 游戏更新挪了偏移，需重定位 |

## 2. 入站（队友 → 我）

先打开调试：设置 → 勾「调试：把每一条聊天原始行写进日志」，保存（2 秒生效）。

加入一个队伍（好友或随机匹配），让队友发一句英文；自己也可以先发一句触发 `self_name` 学习。

证据顺序：

- [ ] `CHAT name="队友名" body="enemy ahead"`（原始行）
- [ ] `INBOUND queued idx=... from="队友名"`
- [ ] `INBOUND request idx=... lane=helper`
- [ ] `INBOUND translated idx=... text="[EN] 前方有敌人"`
- [ ] 游戏里那一行下面出现 `[EN] 中文`

失败分支：

| 日志 | 含义 |
|---|---|
| `INBOUND idle: own name not learned yet` | 先自己发一条，mod 才知道哪个名字是自己 |
| `TRANSLATE skipped by service` | 控制台判定同语言/系统消息；看控制台记录里的 reason |
| `TRANSLATE failed raw=...` | API Key/网络/模型报错，原文在 raw 里 |
| `INBOUND revert` | 写入失败，行恢复原样（通常是行还没排出来，会自动重试） |

## 3. 系统消息识别（重点）

在飞船/任务里观察聊天栏，把**不是玩家说话**的行（加入/离开/踢人/连接/主机迁移）与日志对照：

- [ ] 记录它们的 `CHAT name="..." body="..."` 原文
- [ ] 若 `name` 为空 → 现有 `is_system_message` 已按空名跳过
- [ ] 若 `name` 是固定词（SYSTEM/系统/…）→ 加进设置里的「系统发送者名字」
- [ ] 若是本地玩家名 + 通知正文 → 加进「系统消息前缀」
- [ ] 确认这些行**没有** `INBOUND translated`

把样本填进 `docs/系统消息样本.md`（新建），后续据此收紧规则。

## 4. 出站（我 → 队友）

- [ ] 自己发一句中文「前方有敌人」
- [ ] 约 1 秒后出现第二条 `[EN] Enemies ahead!`，署名是自己
- [ ] 日志：`OWN message` → `TRANSLATE ok` → `MSEND armed` → `MSEND ok sent=1`
- [ ] `SEND verified ... ms` 证明消息进了聊天环

失败分支：

| 日志 | 含义 |
|---|---|
| `MSEND failed` | 游戏没在 1.5 秒内消费状态字节 → 译文留在输入框，按回车可发（降级） |
| `TRANSLATE skipped by service` | 源语言=目标语言（例如你打英文、发送语言也是英文） |
| `SKIP translate reason=body_too_long` | 单条太长 |

## 4b. 控制台发言（中文输入法被游戏卡住时）

HD2 对中文 IME 处理有 bug（组字时卡控制/弹焦点）。用控制台输入：

- [ ] 游戏在**飞船或任务**里（标题界面聊天面板没运行）
- [ ] 控制台 → 概览 → 控制台发言 → 输入中文 → 翻译并发送
- [ ] 日志：`OUTBOX send` → `SEND wrote` → `MSEND armed` → `MSEND ok sent=N`
- [ ] 游戏聊天里出现对应译文
- [ ] 若标题界面发：`MSEND failed`，随后应看到 `MSEND cleared the console text`（0.1.0+）

## 4c. 黑话 / 缩写

- [ ] 快速测试 `sr` → `[EN] 抱歉`，`ms=0`
- [ ] 快速测试 `LOL` → `[EN] 哈哈`，`ms=0`
- [ ] 快速测试 `sr my bad, need backup` → 自然中文（走模型）
- [ ] 出站中文 `666` → `awesome`
- [ ] 控制台发送含黑话的中文（如「牛批，这波带飞」）→ 英文自然

## 5. 字体

- [ ] 中文译文正常显示，不是方框/问号
- [ ] 若方框：游戏 UI 语言不是简体中文，或缺中文字形 → 装「字体前置」类字体 mod，或把游戏语言切到简体中文

## 5b. 标注语义

- [ ] 设置 `source`（默认）→ 译文是 `[EN] 中文`
- [ ] 设置 `arrow` → 译文是 `[EN→CN] 中文`
- [ ] 设置 `target` → 译文是 `[CN] 中文`
- [ ] 自己发出的英文消息仍是 `[EN] ...`（表示“这条是英文”）
- [ ] 改动后同一条消息不应命中旧缓存（缓存的 key 带 tag_mode）

## 5c. 输入法守护 / 无边框

- [ ] 设置里「输入法守护」勾选
- [ ] 切到游戏，设置页状态显示「游戏前台，已切英文模式」
- [ ] 在游戏里按中文输入法：只出字母、不弹候选窗、游戏不弹出
- [ ] 切回桌面，状态显示「待机」，键盘布局恢复中文
- [ ] （可选）退出游戏 → 安装页「改无边框窗口」→ 重启游戏 → 设置里全屏模式为无边框

> 注意：如果把译文写进**控制台发出的消息行**，该行带 “ok” 投递状态，第二行会与 “ok” 叠住。
> 这是测试注入才会出现的组合；真实入站写的是队友的普通行。判断“错位”时请用普通聊天行。

## 6. 性能

- [ ] 日志 `PERF` 行：`ours_max` 应 < 2ms
- [ ] 若 `PERF game=` 很大且集中在 `tag=set:final`，是游戏自己在重排聊天行；可在设置里关占位符（后续加开关）
