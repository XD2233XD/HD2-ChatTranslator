环境检查

首次安装步骤

  1. 安装 HD2 Arsenal（mod 管理器）与 Bingus Shared Loader（Lua 加载器，必须）。
  2. 把 HD2ChatTranslator-0.1.0.zip 拖进 Arsenal 导入，启用后点 Deploy。
  3. 先启动本控制台，再启动游戏；日志出现 ARMED 即加载成功。
  4. 进游戏发一句中文，约 1 秒后应出现 [EN] ... 的第二条消息。

        
部署前请完全退出游戏。手动部署写 data\9ba626afa44a3aa3.patch_1（本 mod）与 patch_2（Bingus），不碰语言包 patch_0，卸载会精确删除这两份。
