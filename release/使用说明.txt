HD2 Chat Translator 1.0.0
绝地潜兵 2 · 聊天翻译（入站 + 出站）+ 本地操作台
适配：Steam build 25480438 / EXE 1.8.46015.0

====================================================================
   一、这是什么
====================================================================

入站：队友说的非中文，自动翻成中文，紧跟原话显示；只有你本机看得到，
      并标注源语言（默认 [EN] 中文…）；系统消息会自动跳过。
出站：你发的中文，约 1 秒后自动补发一条 [EN] 英文，队友也看得见。
控制台：本机网页，管设置、黑话、历史、日志、API Key、一键安装/卸载。

====================================================================
   二、安装（3 步）
====================================================================

1. 解压到一个固定目录（建议非 C 盘，例如 E:\HD2ChatTranslator）。
   目录里应该有 HD2ChatTranslator.exe 和 _internal 文件夹，两个必须在一起。

2. 双击 HD2ChatTranslator.exe，浏览器会自动打开：
      http://127.0.0.1:8731/
   进「设置 → 翻译服务」，填 DeepSeek（或任意 OpenAI 兼容接口）的
   API Key 和模型名，点「保存并生效」。
   然后在「概览 → 快速测试」输入 sr，应该出现 [EN] 抱歉。

3. 先完全退出游戏，回到控制台「安装 / 诊断」：
      * 环境检查应能看到游戏目录
      * 点「一键部署到游戏」
   它会写入两个文件（不碰语言包）：
      data\9ba626afa44a3aa3.patch_1   本 mod
      data\9ba626afa44a3aa3.patch_2   Bingus Shared Loader v20

   然后启动游戏。日志出现 START version=1.0.0 和 ARMED 就成功了：
      %LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\HD2ChatTranslator.log

   已装过旧版的，直接再点一次「一键部署」覆盖即可（GUID 不变）。

====================================================================
   三、日常使用
====================================================================

* 不需要安装 Python 或编译工具。
  Node 是可选的：系统里有 node 时走常驻助手（最快）；没有就自动用 Windows
  自带的 curl，每条消息慢约 0.2 秒，功能一样。
* 保持 HD2ChatTranslator.exe 运行；关掉它翻译会失败并回滚，聊天本身不受影响。
* 游戏里正常打字发送即可。
* 中文输入法在 HD2 里会卡控制/弹焦点，推荐：
      控制台 → 概览 →「控制台发言」
   在浏览器里用中文输入法打字，点「翻译并发送到游戏」；
   它会由 mod 写进聊天框并让游戏自己发出去，不碰游戏内 IME。
* 设置里「输入法守护」默认开启：游戏在前台时自动把键盘布局切英文，
  离开游戏恢复；如果仍然弹，安装页「改无边框窗口」（需退出游戏）后重启。
* 黑话/缩写：sr=LOL=gg=RR=... 内置词典（0ms），组合句交给模型；
  术语表可自己加词。
* 入站显示方式默认 line：译文是一条仅本机可见的独立消息（↳ 前缀）。
  想贴回原行下面，可在设置里切 row。

====================================================================
   四、常见问题
====================================================================

Q: 浏览器没打开 / 页面打不开？
A: 手动访问 http://127.0.0.1:8731/ 。若提示端口占用，先关掉旧的
   HD2ChatTranslator 进程（任务管理器）再启动。

Q: 日志没有 START？
A: 安装页确认「Bingus 已安装 / 本 Mod 已安装」；数据目录里
   data\9ba626afa44a3aa3.patch_1 与 patch_2 是否存在。
   仍不行就改用 Arsenal 导入 mod\HD2ChatTranslator-1.0.0.zip 与
   loader\Bingus-Shared-Loader-v20.zip（加载器放列表最后，Deploy）。

Q: 游戏更新后失效？
A: 内存偏移可能变化。mod 会降级（译文留在输入框，按回车可发），不会崩溃。
   等适配版更新，或按 docs 里的方法重新定位偏移。

Q: API Key 安全吗？
A: Key 只存在本机 %LOCALAPPDATA%\HD2ChatTranslator\console.json，
   不会进日志、不会发给队友。

Q: 会不会被反作弊？
A: 不注入 DLL、不改 EXE、不读写网络协议；只读写游戏自己的聊天 UI
   内存并调用游戏自己的发送流程。与所有 mod 一样，风险自负。

====================================================================
   五、卸载
====================================================================

控制台 →「安装 / 诊断」→「卸载」。
只删除标记匹配的 patch_1 / patch_2，不碰语言包和存档。
然后删除本程序目录即可。
